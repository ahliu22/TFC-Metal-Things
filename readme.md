TFC Metal Things

Add more useful metal things for TFC.  
Handstone: higher durability  
Spindle head and spindle: higher durability  
Support beam: bigger support range  
Door, fence and fence gate: new decors  

This mod also adds a new tooltip to show the support range of support beams.


群峦金属物件

给群峦传说加入了更多有用的金属物件。  
手推磨磨盘：耐久更高  
纺锤头和纺锤：耐久更高  
支撑梁：支撑范围更大  
门、栅栏、栅栏门：新的装饰方块  

同时给支撑梁添加了tooltip可以显示支撑范围。
